# Monthly client report outline

Eight sections, in the order a client reads them. The summary goes first because for many clients it is the only part they read — which is also why sections 5 and 7 have to be in it.

Title it: **Monthly client report — [Client] — [Month YYYY]**

## 1. Summary

Three to five bullets: top wins, key numbers against target, the main issue, and next month’s focus.

## 2. Goals and KPIs

| KPI | Target | This month | Last month | Change |
|---|---|---|---|---|
|  |  |  |  |  |

## 3. Work completed

Deliverables shipped, with links.

## 4. Results and insights

What worked, what did not, and why.

## 5. Issues and risks

Blockers, items waiting on the client, and a proposed fix for each.

## 6. Next month’s plan

Priorities, owners, dates.

## 7. Requests for the client

Approvals, access or input you need, each with a due date.

## 8. Budget and hours

Used against planned, and any out-of-scope work.

> If a KPI moved the wrong way, it goes in section 1, not buried in section 4. A client who finds bad news on page three stops trusting page one.
