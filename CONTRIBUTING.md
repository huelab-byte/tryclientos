# Contributing
Thanks for helping! Please:
1. One pull request per addition. Put it in the right section, alphabetical where possible.
2. Format: `- [Name](https://link) - Short neutral description.` (end with a period, no marketing superlatives).
3. Only add tools that are live, publicly available and relevant to agency/service-business client work.
4. Disclose if you work for or are affiliated with the tool you add.
5. Templates must be original or CC0-compatible, practical and vendor-neutral.
6. Check links work before submitting. Dead links are removed.
By contributing you agree your work is released under CC0 1.0.
